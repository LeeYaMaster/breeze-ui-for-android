# Breeze UI 组件文档站（静态）

Ant Design 风格的组件演示与 API 速查，对应 Jetpack Compose 库 `com.breeze.ui:breeze-ui` **1.3.0**。

- `gallery-pages.js`：侧栏导航与各组件页（演示 + API 表）
- `app.js`：路由、主题、通用交互初始化
- `styles.css`：布局与 Web 近似组件样式

## 打开

- 本地：浏览器打开 [`index.html`](./index.html)（`file://` 即可，无需 npm）。
- 本地服务（可选）：`python3 -m http.server 8080 --directory docs/site`
- GitHub Pages（已配置）：源分支 `main`、文件夹 **`/docs`** → [在线演示](https://leeyamaster.github.io/breeze-ui-for-android/site/)（`docs/index.html` 重定向到 `site/`）。

完整 API 与接入说明见 [API.md](../API.md)、[DEVELOPER_GUIDE.md](../DEVELOPER_GUIDE.md)。

> Web 预览为近似效果，真机以 Jetpack Compose 为准。
