# Breeze UI — 浏览器效果预览

> **推荐**：新版分组件文档站见 [`../site/index.html`](../site/index.html)（侧栏导航 + API 表）。

无需安装 Android 或运行 Gradle，即可在浏览器中查看 Breeze UI For Android 的品牌色、按钮按压、进度条、分段控件与点赞动效等**视觉近似**演示。

## 打开方式

1. **本地**：在文件管理器中双击 [`index.html`](./index.html)，或用浏览器打开该文件（支持离线）。
2. **GitHub / Gitee**：在仓库中浏览 `docs/preview/index.html`（部分平台支持直接预览 HTML；若仅显示源码，请下载后用浏览器打开）。
3. **GitHub Pages / Gitee Pages**（若已配置）：将站点根目录或 `docs/` 指到本目录后，访问 `/preview/index.html`。

## 说明

页面为纯静态 HTML/CSS/JS，**不**等同于 Jetpack Compose 运行时。真实交互、无障碍与性能以 `:app` 演示应用及 `breeze-ui` 库为准。开发接入见 [DEVELOPER_GUIDE.md](../DEVELOPER_GUIDE.md)。
