# 类型说明（JS / TS）

组件库为 **JS** 和 **TS** 都提供了类型信息，便于在编辑器里获得提示和校验。

---

## JS 项目

- 每个组件的 **`index.js`** 都带有 **JSDoc**（含 `@typedef` 等）。
- 在 VSCode / Cursor 等编辑器中打开引用组件的页面或组件时，会看到**属性名、方法、参数**的提示和说明。
- 若在 **`jsconfig.json`** 中开启 `"checkJs": true`，还可利用 JSDoc 做一定的类型检查。

无需额外配置，复制 `breeze-ui` 使用即可。

---

## TS 项目

- 每个组件目录下都有 **`index.d.ts`**，导出该组件的 **Props**（及部分 **Methods**）。
- 可从总入口引用类型：
  ```ts
  import type { ButtonProps, ModalProps, ToastMethods } from '/breeze-ui/components';
  ```
- 或从单个组件引用：
  ```ts
  import type { ButtonProps } from '/breeze-ui/components/button/index';
  ```

### Toast 命令式 API（推荐）

```js
const Toast = require('/breeze-ui/utils/toast');

Toast.success('操作成功');
Toast.error('提交失败');
Toast.showErrors(errors);

// 顶部提示
Toast.top.success('保存成功');
Toast.top.error('网络异常');
```

页面需挂载全局反馈层。推荐用 `<bz-page>`（默认含 Toast）；或手动 `<bz-toast global />` / `<bz-toast-top global />`。仍兼容 `selectComponent` + `setShow`：

```ts
const toast = this.selectComponent('#toast') as WechatMiniprogram.Component.TrivialInstance & import('/breeze-ui/components/toast/index').ToastMethods;
toast.setShow('success', '操作成功');
// 或对象参数
toast.setShow({ status: 'success', message: '操作成功', time: 2000 });
```

顶部 Toast：

```ts
const toastTop = this.selectComponent('#toast-top') as WechatMiniprogram.Component.TrivialInstance & import('/breeze-ui/components/toast-top/index').ToastTopMethods;
toastTop.setShow('success', '保存成功');
Toast.top.success('保存成功');
```

### Modal 命令式 API

```js
const Modal = require('/breeze-ui/utils/modal');

Modal.confirm({ title: '确认', content: '是否继续？' });
Modal.alert('操作成功');
```

---

## 类型文件位置

| 内容 | 位置 |
|------|------|
| 各组件 Props / Methods | `breeze-ui/components/<组件名>/index.d.ts` |
| 汇总导出 | `breeze-ui/components/index.d.ts` |

新增或修改组件时，同步维护对应 `index.d.ts` 和 JSDoc，即可保持类型与文档一致。
