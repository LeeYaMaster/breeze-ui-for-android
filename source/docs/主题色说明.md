# 主题色说明

本文说明本仓库里主题色是如何通过 CSS 变量生效的，以及为什么写 `class="bg-theme"` 就能拿到对应颜色。

---

## 一、结论先说

能拿到颜色，靠的是 **「祖先定义变量 + 后代用变量」**，不是单靠一个 `bg-theme`。

- 必须有一个**祖先**节点带有 `theme-wrap` 和某个主题 class（如 `theme-blue`），在 **breeze-ui/theme.wxss** 里为这个祖先**定义**了 `--theme-primary` 等变量。
- 带 `bg-theme` 的节点必须是该祖先的**后代**，这样使用 `var(--theme-primary)` 时才会从祖先继承到值。

所以起作用的是「祖先的 theme-wrap + 主题 class」和「后代的 bg-theme」一起配合。

---

## 二、theme.wxss 里做了哪两件事

文件 **breeze-ui/theme.wxss** 做了两件事。

### 1. 在「带主题的包裹层」上定义变量

谁有 `theme-wrap` + 某个 `theme-xxx`，谁就被赋上对应的颜色变量：

```css
.theme-wrap.theme-default { --theme-primary: #5b6cff; ... }
.theme-wrap.theme-blue    { --theme-primary: #0081ff; ... }
.theme-wrap.theme-purple  { --theme-primary: #6739b6; ... }
.theme-wrap.theme-orange  { --theme-primary: #f37b1d; ... }
.theme-wrap.theme-red     { --theme-primary: #e54d42; ... }
.theme-wrap.theme-cyan    { --theme-primary: #1cbbb4; ... }
```

也就是说：只有同时具备 `theme-wrap` 和 `theme-default` / `theme-blue` / … 的节点，才会被赋上对应的 `--theme-primary`、`--theme-light`、`--theme-gradient` 等。

### 2. 在「包裹层内部」使用变量

后代用 `var(--theme-primary)` 去读这些变量：

```css
.theme-wrap .bg-theme {
  background-color: var(--theme-primary);
}
.theme-wrap .text-theme {
  color: var(--theme-primary);
}
.theme-wrap .bg-theme-light {
  background-color: var(--theme-light);
}
.theme-wrap .theme-gradient {
  background: var(--theme-gradient);
}
```

含义是：**在带有 `theme-wrap` 的节点下面的**、class 为 `bg-theme` 的元素，背景色用 `var(--theme-primary)`。`var(--theme-primary)` 会沿 DOM 向上查找，找到上面那个 `.theme-wrap.theme-xxx` 里定义的 `--theme-primary`，所以最终颜色就是当前主题的主色。

---

## 三、用结构串起来看

```html
<view class="theme-wrap theme-blue">
  <!-- 这里定义了 --theme-primary: #0081ff -->
  <view class="bg-theme">...</view>
  <!-- 这里用 var(--theme-primary)，得到 #0081ff -->
</view>
```

- **没有**外面的 `theme-wrap theme-blue`，就没有节点定义 `--theme-primary`，里面的 `bg-theme` 用 `var(--theme-primary)` 也拿不到颜色。
- **有**外面的 `theme-wrap {{themeClass}}`（例如 `theme-blue`），theme.wxss 里对应的规则就会给这个 view 写上 `--theme-primary`，里面的 `bg-theme` 就能拿到对应颜色。

---

## 四、为什么「光凭 theme.wxss 的 CSS」就能让 bg-theme 有颜色？

因为 **theme.wxss 同时做了两件事**：

1. 在带 `theme-wrap` + 主题 class 的**祖先**上**定义**变量（如 `--theme-primary`）。
2. 在 `theme-wrap` 的**后代**上，用 `.bg-theme` 等 class **使用**变量（`var(--theme-primary)`）。

CSS 变量会**继承**：子节点用 `var(--theme-primary)` 时，会向上找到祖先里定义的那个值。所以只要页面上有「带 theme-wrap 和主题 class 的祖先」，其内部的 `bg-theme` 就能拿到主题色；单写一个 `class="bg-theme"` 而不在任意祖先上挂 `theme-wrap` + 主题 class，是拿不到主题色的。

---

## 五、在项目里怎么用

### 演示工程（一键换肤）

1. 调用 **`breeze-ui/utils/theme.js`**：`Theme.setTheme('theme-blue')` 会写入缓存、更新 `app.globalData.themeClass`，并 `setData` 到当前页面栈内所有 Page。
2. 页面 / 组件引入 **`utils/theme-behavior.js`**，根节点 `<view class="theme-wrap {{themeClass}}">` 包住内容；Behavior 在 `attached` / `show` 时自动 `Theme.syncPage(this)`。
3. 演示区 `bg-gradual-breeze`、`text-breeze` 在 `breeze-ui/theme.wxss` 中已映射为 `var(--theme-gradient)` / `var(--theme-primary)`，换肤后导航栏与 Hero 同步变色。

可选主题 id：`theme-default`（Breeze）、`theme-blue`、`theme-purple`、`theme-orange`、`theme-red`、`theme-cyan`。

### 手动接入

1. **需要主题的页面**：根节点用 `<view class="theme-wrap {{themeClass}}">` 包住整页内容，并在该页的 onShow/onLoad 里从 `Theme.getThemeId()` 或缓存读取并 `setData({ themeClass })`。
2. **切换主题**：`Theme.setTheme(id)`（或绑定 Behavior 的 `onThemePick`）。
3. **在 theme-wrap 内部**：任意子节点加 `class="bg-theme"`、`class="text-theme"`、`class="bg-theme-light"` 或 `class="theme-gradient"` 即可使用当前主题色；也可在样式中直接写 `var(--theme-primary)`、`var(--theme-light)`、`var(--theme-gradient)`。

已引入 `breeze-ui/theme.wxss` 后，上述 class 和变量即可生效。
