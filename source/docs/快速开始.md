# 快速开始

5 分钟在自己的微信小程序项目里用上 Breeze UI 组件库。

---

## 一、接入已有项目（3 步）

### 1. 复制组件库目录

将本仓库中的 **`breeze-ui`** 文件夹整体复制到你的小程序项目根目录下，与 `app.js`、`pages` 同级：

```
你的项目/
├── app.js
├── app.json
├── app.wxss
├── breeze-ui/          ← 复制整个文件夹
│   ├── main.wxss
│   ├── icon.wxss
│   ├── iconfont.wxss
│   ├── animation.wxss
│   ├── styles/          # 样式分层目录
│   ├── utils/           # 库内部工具
│   └── components/
│       ├── button/
│       ├── modal/
│       └── ...
├── pages/
└── ...
```

### 2. 引入样式

在 **`app.wxss`** 最顶部增加：

```css
@import "breeze-ui/main.wxss";
@import "breeze-ui/theme.wxss";
@import "breeze-ui/icon.wxss";
@import "breeze-ui/iconfont.wxss";
@import "breeze-ui/animation.wxss";
```

> **样式结构**：`main.wxss` 已拆为 `breeze-ui/styles/`（tokens / 工具类 / 组件样式）。全量引入方式不变；按需引入见 [breeze-ui/styles/README.md](../breeze-ui/styles/README.md)。

### 3. 注册要用的组件

在 **`app.json`** 的 **`usingComponents`** 里按需注册，例如只用按钮和模态框：

```json
{
  "usingComponents": {
    "bz-custom": "/breeze-ui/components/bz-custom/index",
    "bz-button": "/breeze-ui/components/button/index",
    "bz-modal": "/breeze-ui/components/modal/index"
  }
}
```

**全部组件** 的注册方式见 [组件清单](./组件清单.md)。

### 统一点击事件

所有组件均支持 **`bind:tap`**，与组件原有事件（如 `bind:tabSelect`、`bind:click`）并存：

```xml
<bz-button bind:tap="onButtonTap">按钮</bz-button>
<bz-tag bind:tap="onTagTap">标签</bz-tag>
```

```js
onButtonTap(e) {
  console.log(e.detail); // { dataset: {...}, ... }
}
```

## 二点五、Toast / Modal 命令式 API（推荐）

### 方式一：bz-page 布局（推荐）

用 **`bz-page`** 包住页面内容，默认已挂载全局 Toast；需要 Modal API 时加 `modal` 属性：

```xml
<bz-page>
  <!-- 页面内容 -->
</bz-page>

<!-- 需要 Modal.confirm / Toast 时 -->
<bz-page toast modal>
  ...
</bz-page>

<!-- 需要顶部提示时 -->
<bz-page toast toastTop>
  ...
</bz-page>

<!-- 需要 ActionSheet.show 时 -->
<bz-page toast actionSheet>
  ...
</bz-page>
```

### 方式二：手动挂载

```xml
<bz-toast global />
<bz-modal global />
```

在 JS 中直接调用（无需 `selectComponent`）：

```js
const Toast = require('../../breeze-ui/utils/toast');

Toast.success('操作成功');
Toast.error('提交失败');
Toast.show({ status: 'success', message: '自定义文案', time: 2000 });

// 配合 bz-form 校验失败
Toast.showErrors(errors);
```

### 表单 model 双向绑定（推荐）

无需每个字段写 `onFieldChange`，使用 `model:model`：

```xml
<bz-form id="form" model:model="{{form}}" rules="{{rules}}" bind:submit="onSubmit">
  <bz-form-field name="phone" label="手机号" value="{{form.phone}}">
    <bz-input hideLabel value="{{form.phone}}" placeholder="请输入手机号" />
  </bz-form-field>

  <bz-form-field name="gender" label="性别" value="{{form.gender}}">
    <bz-radio-group hideLabel options="{{genderOptions}}" value="{{form.gender}}" />
  </bz-form-field>

  <bz-form-field name="hobbies" label="兴趣" value="{{form.hobbies}}">
    <bz-checkbox-group hideLabel options="{{hobbyOptions}}" value="{{form.hobbies}}" />
  </bz-form-field>

  <bz-form-field name="pet" label="宠物" value="{{form.pet}}">
    <bz-picker hideLabel type="normal" picker="{{petOptions}}" value="{{form.pet}}" />
  </bz-form-field>
</bz-form>
```

```js
data: {
  form: { phone: '', gender: '', hobbies: [], pet: '' },
  rules: {
    phone: [{ required: true }, { type: 'phone' }],
    gender: [{ required: true, message: '请选择性别' }],
    hobbies: [{ min: 1, message: '至少选一项' }],
    pet: [{ required: true, message: '请选择宠物' }],
  },
},
handleReset() {
  this.selectComponent('#form').resetFields(); // 自动 sync model
},
```

**顶部提示**（`bz-toast-top`）用法一致：

```xml
<bz-toast-top global />
```

```js
Toast.top.success('保存成功');
Toast.top.error('网络异常');
Toast.showTop({ status: 'success', message: '自定义文案', time: 3000 });
// 等价写法
Toast.top.show({ status: 'error', message: '失败' });
```

仍兼容旧写法 `this.selectComponent('#toast').setShow('success', '消息')` 及 `toast-top.setShow('success', '消息')`。

### Modal / Dialog 命令式 API

若未使用 `<bz-page modal>`，需手动挂载：

```xml
<bz-modal global />
```

```js
const Modal = require('../../breeze-ui/utils/modal');

Modal.confirm({
  title: '确认删除',
  content: '删除后无法恢复，是否继续？',
}).then(() => {
  // 确认
}).catch(() => {
  // 取消
});

Modal.alert('操作成功');
Modal.show({ title: '提示', content: '自定义内容' });
Modal.hide();
```

找不到 `bz-modal` 时，`confirm` / `alert` 会降级为 `wx.showModal`。

### ActionSheet 命令式 API

```xml
<bz-page actionSheet />
<!-- 或 -->
<bz-action-sheet global />
```

```js
const ActionSheet = require('../../breeze-ui/utils/action-sheet');

ActionSheet.show({
  title: '请选择',
  actions: [
    { name: 'share', text: '分享', color: 'blue' },
    { name: 'delete', text: '删除', color: 'red' },
  ],
}).then((action) => {
  console.log(action.name);
}).catch(() => {});
```

找不到 `bz-action-sheet` 时降级为 `wx.showActionSheet`。

## 二点六、Flex 布局用法推荐

ColorUI / Breeze UI 的 Flex **优先用 CSS 工具类**，不是 Ant Design 那样必须用布局组件。

### 推荐写法（日常 90% 场景）

```xml
<view class="flex justify-between align-center padding">
  <view class="flex-sub bg-grey padding-sm radius">左</view>
  <view class="flex-twice bg-grey padding-sm radius">右</view>
</view>
```

常用 class 见 `breeze-ui/styles/utilities/layout.wxss`：`.flex`、`.flex-sub` / `.flex-twice` / `.flex-treble`、`.flex-direction`、`.justify-*`、`.align-*` 等。

### 可选：组件写法

`bz-flex` / `bz-flex-item` 已开启 **`virtualHost`**（需基础库 **≥ 2.11.2**，2020-06 起），与上面 `view` 写法等价：

```xml
<bz-flex class="justify-between align-center padding">
  <bz-flex-item extraClass="bg-grey padding-sm radius">左</bz-flex-item>
  <bz-flex-item multiple="2" extraClass="bg-grey padding-sm radius">右</bz-flex-item>
</bz-flex>
```

- `multiple="1|2|3"` 对应 `flex-sub` / `flex-twice` / `flex-treble`
- 布局 class 写在 `class` 或 `extraClass` 上

### 为何不全封装成组件？

小程序自定义组件默认**多一层节点**，Flex 只对**直接子元素**生效；未处理时会出现「组件隔一层、布局失效」。应用 `virtualHost` 后可对齐原生 `view`，但纯布局仍**工具类更轻、更灵活**。

详细原理、与 Ant Design 对比、设计取舍见 **[learn.md — Flex 布局附录](./learn.md#附录flex-布局--工具类-vs-组件2026-06-补充)**。

演示：**元素 → 布局**（含组件写法与原生 view 对比）。

## 四、自定义导航栏（可选）

若使用 `bz-custom` 自定义导航栏，需在 **`app.js`** 的 `onLaunch` 里写入状态栏/胶囊数据，供导航栏计算高度：

```javascript
App({
  onLaunch() {
    wx.getSystemInfo({
      success: (e) => {
        this.globalData.StatusBar = e.statusBarHeight;
        const capsule = wx.getMenuButtonBoundingClientRect();
        if (capsule) {
          this.globalData.Custom = capsule;
          this.globalData.CustomBar =
            capsule.bottom + capsule.top - e.statusBarHeight;
        } else {
          this.globalData.CustomBar = e.statusBarHeight + 50;
        }
      },
    });
  },
  globalData: {
    StatusBar: 0,
    CustomBar: 0,
    Custom: null,
  },
});
```

## 五、主题色 / 一键换肤（可选）

演示工程已接入**全局换肤**：在 **关于 → 一键换肤** 或 **页面 → 主题切换** 选择主题后，会写入本地缓存并同步到当前栈内所有页面。

### 演示工程用法

1. Tab 根页 `pages/index/index` 已包裹 `theme-wrap {{themeClass}}`，子 Tab 内的 `bg-gradual-breeze` / `text-breeze` 会随主题变化。
2. 各演示子页已通过 `utils/theme-behavior.js` 自动同步 `themeClass`，根节点同样包裹 `theme-wrap`。
3. 新增演示入口只需改 [`utils/demo-catalog.js`](../utils/demo-catalog.js)，`npm run check` 会校验路径是否存在。
4. 切换 API 见 `breeze-ui/utils/theme.js`：`Theme.setTheme(id)`、`Theme.getThemeId()`、`Theme.syncPage(page)`。

### 接入到自己的页面

在需要主题的页面根节点用 **`<view class="theme-wrap {{themeClass}}">`** 包住内容，并引入 Behavior：

```js
const themeBehavior = require('../../utils/theme-behavior');

Page({
  behaviors: [themeBehavior],
  // themeClass 由 Behavior 在 attached / show 时自动 sync
});
```

切换主题时调用 `Theme.setTheme('theme-blue')`（或绑定 `onThemePick`）。已引入 `breeze-ui/theme.wxss` 后，在 `theme-wrap` 内使用 `var(--theme-primary)` 或类名 `.bg-theme`、`.text-theme`。详见 **docs/主题色说明.md**。
